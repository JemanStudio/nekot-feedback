# Nekot feedback

Bug reports and feature requests for [Nekot](https://jeman.net/nekot/), a Jeman app for iPhone.

- **Found a bug?** [Open a bug report](../../issues/new?template=bug_report.yml)
- **Have an idea?** [Suggest a feature](../../issues/new?template=feature_request.yml)
- **Need help or have a question about a purchase?** See the [Nekot help page](https://jeman.net/nekot/support/) or email [support@jeman.net](mailto:support@jeman.net).
- **Security or privacy issue?** Please follow our [security policy](https://github.com/JemanStudio/.github/blob/main/SECURITY.md) instead of opening a public issue.

Never post tokens, passwords, session cookies or account emails. Please crop or blur them from screenshots before posting.

This repository only tracks feedback. Nekot is not open source.
